# Калькулятор подушек / AI-CRM Misterpufik

Локальный сайт для расчёта себестоимости и стоимости заказа по позициям + CRM на хостинге.

## Открыть во втором аккаунте Cursor

1. В Cursor (новый аккаунт): **Clone repo** или в терминале:

```powershell
git clone https://github.com/misterpufik-ship-it/calkulator-misterpufik.git
```

2. Откройте склонированную папку в Cursor (**File → Open Folder**).
3. Создайте `.env` из шаблона и заполните секреты (файл `.env` в GitHub не лежит — его передают отдельно):

```powershell
copy .env.example .env
```

4. Запустите локальный сервер:

```powershell
python server.py
```

Сайт: http://127.0.0.1:4173

Подробные правила хостинга и деплоя: [docs/PROJECT.md](docs/PROJECT.md)

## Как открыть (локально)

В папке проекта запустите локальный сервер:

```powershell
python server.py
```

После этого сайт будет доступен по адресу:

```text
http://127.0.0.1:4173
```

## Что внутри

- `index.html` - разметка сайта.
- `styles.css` - оформление интерфейса.
- `app.js` - расчётная логика, настройки, история заказов и работа с интерфейсом.
- `server.py` - локальный сервер и генерация КП в Word/PDF.

Значения на вкладке "Значения" взяты из Excel-файла и сохраняются в браузере.
Реквизиты, печать и подпись заполняются на вкладке "Реквизиты".
Готовые КП сохраняются в `outputs/proposals/`.

## Подключение Google Таблицы для аренды

1. Откройте нужную Google Таблицу.
2. Меню: `Расширения` -> `Apps Script`.
3. Вставьте код из `google-apps-script-rental.js`.
4. Нажмите `Развернуть` -> `Новое развертывание`.
5. Тип: `Веб-приложение`.
6. Доступ: `Все, у кого есть ссылка`.
7. Скопируйте URL веб-приложения и вставьте его на вкладке `Аренда`.
